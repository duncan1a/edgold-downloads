# Download EdGold Hebrew Suffixes

EdGold is a floating panel with 26 large Hebrew keys. Place the cursor in WordCraft or another text editor, then click a key to insert a suffix at the cursor.

## Install on Mac

1. Open the downloaded ZIP to extract it.
2. Open **System Settings → Accessibility → Keyboard → Panel Editor**.
3. In the **Accessibility Keyboard Active Panel Collection**, choose **File → Import Panels** and select **EdGold Hebrew Suffixes.ascconfig**. If you already have an older EdGold panel, remove that panel before importing. Press **⌘S** to save.
4. Turn on **Accessibility Keyboard** in the same Keyboard settings. On the floating keyboard, open **Custom Panels → EdGold Hebrew Suffixes**.

The panel runs inside the Mac's built-in keyboard. See [Apple's guide to the Panel Editor](https://support.apple.com/guide/mac-help/panel-editor-switch-control-accessibility-mh43606/mac).

## Install on Windows

1. Open the downloaded **Setup.exe** and follow the installer prompts. You don't need administrator rights or a separate runtime. The installer is unsigned, so Windows may show a publisher warning.
2. Open **Start**, search for **EdGold Hebrew Suffixes**, and launch it.

## Try it in WordCraft

Type <bdi dir="rtl">סוס</bdi>, leave the cursor immediately after the word, and click the top-left key on the panel. You should see <bdi dir="rtl">סוסִים</bdi>.
